# AIP-C01 learning content (markdown)

Extracted from the HTML study site so the teaching material can be read, searched and edited as plain files.

This is **not** a replacement for the site. Interactive widgets, the exam simulator, Leitner flashcards and progress tracking still live in `src/` / `docs/`. These files are the actual writing: modules, labs, question explanations, flashcard copy, and the teaching notes that were embedded in widgets.

**Exam:** AWS Certified Generative AI Developer – Professional (`AIP-C01`).

Always confirm service behaviour and prices against current AWS documentation. The official exam guide is the authority on scope.
